# Code of conduct

Participation in this project (issues, pull requests, discussions) is expected to be respectful and
focused on the work. Disagreements about methods and assumptions are welcome and should be argued with
sources or data. Harassment, insults and personal attacks are not accepted, and the maintainer may edit
or remove comments and close threads that break this rule.

To report a conduct problem, write to the maintainer at the address in the `DESCRIPTION` file.
